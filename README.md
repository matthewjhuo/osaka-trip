# 🏯 Osaka 遊記 · 大阪 6 天 5 夜行程書

以米白色旅行手冊為視覺風格的旅遊行程 Web App，採用手機優先設計，以純 HTML、CSS 與 JavaScript 製作，無需安裝套件或建置。

預設行程為 **2026/12/09–12/14，大阪與關西 6 天 5 夜**。出發日期、航班與行程可依需求調整。

## 功能

- **首頁看板**：每日行程預覽、出發秒數倒數、航班資訊、景點與美食推薦、住宿與旅遊提醒。
- **每日行程**：日期切換、單日時間軸、全行程總覽、新增／編輯／刪除行程，以及每日筆記。
- **互動地圖**：透過 Leaflet 顯示當日行程與備用景點，支援目前位置定位與 Google Maps 導航連結。
- **旅費記帳**：新增與刪除日圓支出、每日與累積金額、付款人與分攤人數記錄，以及日圓／台幣雙向換算。
- **備用景點**：收藏地點，將推薦景點、美食或收藏加入指定日期的行程。
- **行前清單**：勾選準備項目、查看完成進度，並新增自訂項目。
- **行程設定**：調整出發日期、起飛時間與換算匯率，或還原預設資料。

## 開始使用

下載或複製此專案後，直接以瀏覽器開啟 `index.html` 即可使用。也可以透過本機 HTTP 伺服器預覽：

```bash
# 已安裝 Python 時，在專案目錄執行
python -m http.server 8000
```

接著開啟 [http://localhost:8000](http://localhost:8000)。

地圖、字型、照片與即時天氣需要網路連線。目前位置定位需要瀏覽器授權，建議使用 HTTPS 或 localhost。

## 自訂行程

編輯 `data.js` 中的 `TRIP_DEFAULT`，可設定：

- 出發日期、起飛時間與預設匯率。
- 每日行程、交通提示與地點座標。
- 航班、住宿、推薦景點、美食、備用景點與行前清單。

地圖標記依賴地點的 `lat`、`lng` 座標；僅填入名稱的新增行程仍可使用 Google Maps 搜尋連結。

瀏覽器會優先載入已儲存的行程。修改 `data.js` 後，若仍顯示舊內容，可在設定中選擇「還原預設值」；此操作也會清除該瀏覽器中的記帳、筆記與清單勾選紀錄。

## 資料儲存與使用限制

- 行程、記帳、筆記與清單進度儲存在目前瀏覽器的 `localStorage`，不會自動跨裝置同步。清除網站資料會移除這些紀錄。
- 匯率由使用者設定，並非即時匯率。
- 天氣由 Open-Meteo 提供，顯示查詢當下起的六日預報，不一定對應旅行日期。目前連線失敗時的備援數值為程式產生，請勿作為實際預報。
- 分帳目前提供付款人與分攤人數記錄，尚無逐人結算功能。
- 提供 Web App manifest，方便支援的瀏覽器加入主畫面；目前沒有 Service Worker 或完整離線快取。
- 航班、住宿與旅遊提醒為行程資料，出發前請自行確認最新資訊。公開部署前，請檢查是否包含訂位代碼或其他個人資料。

## 部署至 GitHub Pages

1. 將專案推送至 GitHub 儲存庫。
2. 在儲存庫的 **Settings → Pages** 中，選擇 **Deploy from a branch**。
3. 選擇 `main` 分支與 `/ (root)` 目錄，儲存後等待部署完成。
4. 使用 Pages 顯示的網站網址開啟。

## 專案結構

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 頁面結構與導覽 |
| `style.css` | 手機版面、卡片與彈出視窗樣式 |
| `app.js` | 互動邏輯、地圖、天氣、記帳與本機儲存 |
| `data.js` | 預設行程與旅遊內容 |
| `manifest.json` | 加入主畫面的 Web App 設定 |
| `icon.svg` | 應用程式圖示 |

## 使用技術

HTML5、CSS3、原生 JavaScript、[Leaflet](https://leafletjs.com/)、OpenStreetMap／CARTO 地圖圖磚、[Open-Meteo](https://open-meteo.com/) 天氣資料與 Google Fonts。
